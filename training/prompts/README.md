## 추가·수정하는 방법

1. **새 프롬프트 추가**: `00-template.md`를 복사해 다음 번호로 저장한다(예: `21-…md`). 위 목차 표에 한 줄 추가한다.
2. **원문은 고치지 않는다.** 오타·띄어쓰기도 그대로 둔다. 교재의 설득력은 실제 원문에서 나온다.
3. **고쳐 쓰고 싶은 내용**은 "교육용으로 다듬은 프롬프트"와 "메모" 칸에 쓴다.
4. 방법론 단계를 바꾸면 `../docs/methodology.md`와 이 목차의 "방법론 단계" 열을 함께 고친다.
5. 슬라이드·워크북은 이 기록을 원문으로 쓴다. 기록을 고친 뒤 슬라이드에 반영하려면 해당 장 번호를 `../docs/draft.md`에서 찾는다.
