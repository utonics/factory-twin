# 20. (부록) 프롬프트 기록집과 방법론 중심 재구성 요청

## 원문
> zip으로 배포하고 나머지는 추천대로 진행하자. 우리가 처음 프롬프트 작성부터 이 공장 자동화 설계까지 쭉 진행해 왔잖아. 그래서 시작할 때 쓴 마스터 프롬프트부터 1번부터 끝까지 프로젝트를 완성해 나간 프롬프트들을 전부 하나씩 정리해 줬으면 해. 그걸 바탕으로 내용을 추가하거나 변경할 수 있도록 해서 개발자 교육 자료로 활용하고 싶거든.
>
> 내가 지금 하고 있는 바이브 코딩, 즉 Claude Code를 활용한 개발 방법론을 여기에 적용하려고 하니까 거기에 맞춰서 내용을 구성해 줘.

## Claude Code가 한 일
1. 초안의 결정 사항 6개를 반영(실습 자료는 zip, 나머지 추천안)
2. 프롬프트 18건 + 부록 2건을 한 건 한 파일로 정리(`training/prompts/`), 같은 항목 틀과 빈 템플릿 제공
3. 이번 작업 기록과 전역 CLAUDE.md 규칙을 근거로 방법론을 단계화(`training/docs/methodology.md`)
4. 교육 초안을 방법론 중심으로 재구성(v0.2)

## 사람이 정한 것
| AI의 질문 | 사람의 결정 |
|---|---|
| 실습 저장소 배포 방식 | zip |
| 실습 1 과제·로고·팀 규칙 장·출처·강사 표기 | 추천안 |

## 방법론 포인트
- **프롬프트 기록이 곧 팀 자산이다.** 원문 + 결과 + 검증을 한 틀로 남기면 다음 프로젝트의 출발점이 된다
