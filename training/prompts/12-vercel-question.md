# 12. 배포 가능성 묻기

## 원문
> github를 vercel에 등록하면 화면이 나올까 ?

## 상황
- 기능·점검·개선이 끝나 외부 공유를 고민하는 시점

## 의도
- 배포하기 전에 될지 안 될지, 무엇을 설정해야 하는지 판단을 받는다

## Claude Code가 한 일
1. 근거를 직접 확인
   - `package-lock.json`에 Vercel 빌드 서버용 Linux 바이너리(rolldown·TypeScript 7·lightningcss)가 들어 있는지
   - Vite 8·Vitest의 Node 버전 요구사항
   - 로컬 프로덕션 빌드를 `vite preview`로 띄워 60 FPS로 동작한 기록
2. 결론: "될 가능성이 높지만 실제 배포 전이라 미검증"으로 답함
3. 설정값 표(Vite 프리셋, `npm run build`, `dist`, Node 22+)와 주의점(조직 저장소 접근 권한, 요금제, WebGL)을 정리
4. CLI로 직접 배포하는 방법도 제안하되, 외부 게시라 확인을 받겠다고 함

## 사람이 정한 것
| AI의 질문 또는 제안 | 사람의 결정 |
|---|---|
| 직접 배포할지 | 13번에서 환경 정보 제공 |

## 검증
- 잠금 파일·엔진 요구사항 확인(배포 자체는 미검증으로 명시)

## 결과
- 커밋: 없음

## 방법론 포인트
- **"될까?"에는 근거를 확인한 판단과 "미검증" 표시를 함께 받는다**
- 실제로 문제가 잘 생기는 지점(운영체제별 바이너리, Node 버전)을 짚어 확인했다

## 교육용으로 다듬은 프롬프트

```text
Output: 판단과 근거, 필요한 설정값, 주의점.
Constraints: 확인하지 못한 것은 "미검증"으로 표시한다. 아직 배포하지 않는다.
```
